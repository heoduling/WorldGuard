# Isolated pre-spawn regression fixture

Use only a disposable empty test world. SpawnProbe replaces WorldGuard regions, modifies runtime spawn settings, creates creatures and strikes lightning at64,65,64. Compile against the exact tested core, Bukkit API, WorldGuard, WorldEdit and CounterBridge.jar. It is test code and must be packaged separately from WorldGuard.

The state command exports actual registration counts and global pre-spawn configuration. case covers natural allow/deny, deny-spawn type filtering, halt, custom/plugin reasons, tamed exceptions and world block lists. zap uses native lightning, observes EntityZapEvent and verifies actual pig/transformation state. The probe never subscribes to PreCreatureSpawnEvent or its children.

Compile Counts into CounterBridge.jar. Compile CounterAgent with ASM9.9.1 and package ASM and a Premain-Class manifest into CounterAgent.jar. Start the isolated server with -Daudit.bridge=absolute/CounterBridge.jar and -javaagent:absolute/CounterAgent.jar. Instrumentation counts the pre-event constructor, terminal Location constructor and the two possible WG pre-callback classes only while the test scope is active. Production JARs are untouched.

measure LABEL calls the exact core NaturalSpawner.isValidSpawnPostitionForType on an owner-region callback using a prepared MethodHandle. The position check uses a distant cow to exercise the shared-handler branch followed by the existing distance rejection. It does not simulate a complete natural spawning workload. Warm20000 then five rounds100000 checks. Require same carrier and usable allocation counters. Compare WG9/10 with only WG on the shared table and with exact SuperVanish6.3.0-5 and PhantomControl2.1.1-4. Check both the false and true config states and supported hot reload. Empty-table counts should be zero. With subevent subscriptions, event/location creation continues and WG callbacks should be zero. Weak-reference constructor counts are inferred from verified Location bytecode, not directly counted. CPU, full-server allocation, GC and TPS require separate measurements.
